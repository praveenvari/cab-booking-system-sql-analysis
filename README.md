# Cab Booking System SQL Analysis

## Project Overview

This project demonstrates end-to-end SQL analysis for a Cab Booking platform.
The objective was to analyze customer behavior, driver performance, trip operations, cancellation patterns, and business revenue metrics using SQL queries.

---
## Database Design

The project uses the following tables:

- Customers
- Drivers
- Cabs
- Bookings
- TripDetails
- Feedback

The schema models a real-world ride-hailing platform and supports operational and business analytics.
